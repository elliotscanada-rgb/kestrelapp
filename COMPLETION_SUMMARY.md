## 🎓 How to Customize

### Add New Page
1. Create `NewPage.jsx` in `src/pages/`
2. Add route to `App.jsx`
3. Add navigation link to Navbar
4. Create optional `NewPage.css`

### Change Colors
1. Edit CSS variables in `src/index.css`
2. All pages automatically update

### Update Content
1. Open respective page file
2. Edit text content
3. Refresh browser (auto-reload with Vite)

### Add Images
1. Place in `/public` folder
2. Reference as `/imagename.jpg`
3. Or use CDN URLs
